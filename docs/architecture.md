# Архітектура лабораторного стенду

## Загальна схема

```
┌─────────────────────────┐          ┌──────────────────────────┐
│   Ноутбук з CachyOS      │          │   ПК з віртуальною        │
│   (моніторинг)            │          │   машиною (атакувальник)  │
│                            │          │                            │
│   IP: 192.168.0.209       │◄─────────┤   Kali Linux VM            │
│   Інтерфейс: wlan0        │  трафік  │   IP: 192.168.0.188        │
│                            │          │                            │
│   ┌──────────────────┐    │          │   nmap · ping · ssh ·      │
│   │  Suricata IDS     │    │          │   curl · hydra · ab        │
│   │  (моніторинг)      │    │          │                            │
│   └────────┬──────────┘    │          └──────────────────────────┘
│            │                │
│   ┌────────▼──────────┐    │
│   │  fast.log /        │    │
│   │  eve.json          │    │
│   └────────────────────┘    │
│                            │
│   ┌──────────────────┐    │
│   │  OWASP Juice Shop  │    │
│   │  (Docker, :3000)   │    │
│   └──────────────────┘    │
└─────────────────────────┘
```

## Компоненти

| Компонент | Роль у стенді |
|---|---|
| **CachyOS** (Arch-based Linux) | Основна платформа, на якій розгортається та працює Suricata |
| **Suricata 8.0.4** | IDS-система, аналізує трафік на інтерфейсі `wlan0` і формує журнали спрацювань |
| **Kali Linux VM** | Ізольована віртуальна машина — джерело всієї тестової атакувальної активності |
| **OWASP Juice Shop** | Навчальний вразливий вебдодаток (Docker-контейнер, порт 3000) — ціль для вебатак |
| **Docker** | Ізоляція та швидке розгортання Juice Shop |
| **fast.log / eve.json** | Журнали Suricata — основне джерело даних для аналізу спрацювань |

## Принцип роботи

1. CachyOS виконує роль вузла моніторингу: Suricata запускається в режимі IDS на інтерфейсі `wlan0` і пасивно аналізує весь трафік, що проходить через нього.
2. Kali Linux VM виконує роль атакувального вузла — з неї послідовно виконуються контрольовані тестові дії (ICMP, сканування портів, SSH, HTTP-атаки).
3. Suricata порівнює трафік із локальними правилами (`local.rules`) та стандартним набором Emerging Threats, і при збігу формує запис у `fast.log`.
4. Усі експерименти виконуються виключно в межах локальної ізольованої мережі — жодна дія не виходить за межі лабораторного стенду.

## Мережеві адреси

| Вузол | IP-адреса |
|---|---|
| CachyOS (Suricata + Juice Shop) | `192.168.0.209` |
| Kali Linux VM (атакувальник) | `192.168.0.188` |
| Juice Shop (у Docker на CachyOS) | `192.168.0.209:3000` |
